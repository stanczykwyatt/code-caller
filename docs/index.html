Every 2FA code, one shortcut away

Codes from email and texts

Press ⌃⇧C in any app to copy the newest code from Mail or Messages. Works with Gmail, iCloud, Outlook, Yahoo and any account in Apple Mail.

A built-in authenticator

Press ⌃⇧A, use Touch ID, type a few letters and press Return. Time-based and counter-based codes.

Bring your accounts over

Import from Google Authenticator, Apple Passwords, 1Password, Bitwarden, Aegis, 2FAS, andOTP and rsc/2fa, or a QR code screenshot.

Knows where codes come from

Every copy shows its source, like “Copied from GitHub · Mail · just now”.

Private by design

No internet access, enforced by the macOS sandbox. Nothing it reads is saved, and the clipboard clears itself.

Free and open source

No account, no subscription, no tracking. Every line of code is on GitHub.

Install

  1. Download Copy-2FA.zip and unzip it.
  2. Move Copy 2FA to your Applications folder and open it.
  3. Allow Mail access when asked, then press ⌃⇧C the next time a code arrives.

About the security warning: The first time you open Copy 2FA, macOS may say Apple couldn't verify that it's free of malware. That's not because anything is wrong with the app. Apple charges developers $99 a year to verify their apps, and Copy 2FA hasn't paid that fee yet. The code is fully open source, so you can read every line or build the app yourself. To open it, go to System Settings → Privacy & Security and click Open Anyway.

Questions

How do I copy a 2FA code from email on a Mac?

Add your email account to Apple Mail, open Copy 2FA, and press ⌃⇧C when the code arrives. The newest code is copied, ready to paste with ⌘V.

Does it work with Gmail, Outlook and iCloud?

Yes. Copy 2FA reads every account you've added to Apple Mail, whatever the provider.

Can it read codes from Authy, Duo or Google Authenticator?

Those apps don't let other apps read their codes. Google Authenticator accounts move over with its transfer QR code. Authy doesn't allow exports, so set those accounts up again with a new QR code. Duo passcodes sent by text are read from Messages.

Is it safe?

Copy 2FA can't connect to the internet, only reads messages when you press the shortcut, and keeps authenticator secrets in your keychain behind Touch ID. It's open source, so anyone can check.

Is there a Windows version?

Yes, in preview. It reads Outlook and Thunderbird and has the same authenticator, unlocked with Windows Hello.
