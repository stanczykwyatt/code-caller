The Windows version of Copy 2FA is published as one self-contained `Copy2FA.exe`, so it includes Microsoft's .NET runtime and Windows Desktop runtime. Both are released by the .NET Foundation under the MIT License. Their license texts and the runtime's own third-party notices are in this folder and ship in every Windows download.
