# Code Caller

Tired of digging through your emails for a 2FA code every five seconds? Code Caller copies your newest verification code from Apple Mail with one keyboard shortcut.

It's built for macOS, it's open source, and it has no internet access, so your codes are never accessible to anyone but you.

> Code Caller is in early development. The first release is on its way.
